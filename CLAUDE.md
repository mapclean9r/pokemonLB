# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

pokemonLB is a Pokémon database you can browse: every species (1–1025) with types, base stats, artwork and evolutions, the games they appear in, learnsets per game, and which moves and items exist in which games. Two apps:

| Folder | What | Notes for Claude |
|---|---|---|
| `backend/` | Read-only REST API — Spring Boot 4.1, Java 25, PostgreSQL 17, Flyway | `.claude/rules/backend.md` |
| `frontend/` | Web app — Next.js 16, React 19, TypeScript, Tailwind 4 | `.claude/rules/frontend.md` |

The folder notes are path-scoped rules: they load when working on files in that folder. Read the relevant one before changing anything there.

## How the two apps connect

- The frontend calls the backend at `http://localhost:8080/api/v1` (override with `POKEMON_API_URL` in `frontend/.env.local`). Endpoints are documented with real examples in `backend/docs/api/`.
- Calls go from the Next.js **server** to the API (server components → `frontend/src/services/`), never from the browser, so the backend has no CORS setup. Client-side fetching would need CORS added to the backend first.
- Frontend types in `frontend/src/types/` mirror the backend DTOs in `backend/.../model/dto/`. When a DTO or endpoint changes, update the matching frontend type and service, and the page in `backend/docs/api/`.
- To run both: backend from `backend/` (`.\mvnw.cmd spring-boot:run` in PowerShell, with `JAVA_HOME` set to JDK 25), then `npm run dev` in `frontend/`. The user often has both running already (8080 and 3000); check before starting another instance.

## Tooling

- A PostToolUse hook (`.claude/settings.json` → `.claude/hooks/graphify-update.sh`) refreshes the knowledge graph in `graphify-out/` after Claude edits a file in `backend/` or `frontend/`. See `.claude/rules/graphify.md` for using the graph.
